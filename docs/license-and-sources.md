## Bundled Skill Licenses

Many bundled skills include upstream license files. Preserve those files when copying or redistributing a skill.

Common locations:

```text
skills/<skill-name>/LICENSE.txt
skills/<skill-name>/LICENSE.TXT
skills/<skill-name>/NOTICE.txt
skills/<skill-name>/SKILL.md
```

## Main Sources

- OpenAI skills repository for official Codex skills such as Playwright, Figma, security, deploy, ChatGPT Apps, OpenAI Docs, Sentry, and ASP.NET Core.
- Anthropic Claude Code repository for the frontend-design guidance, installed here as `anthropic-frontend-design` to avoid name conflicts.
- wshobson/agents for practical frontend, backend, API, database, and design-system skill modules.
- Locally authored orchestration skills for `web-fullstack-app`, `swift-apple-app`, and supporting workflow guides.

## Redistribution Rule

If you redistribute a subset, include:

1. The selected skill directory.
2. Its license and notice files.
3. This repository's MIT license if you include local docs, scripts, site, or orchestration material.
