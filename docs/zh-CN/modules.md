## Web 与 UI

| 技能 | 用途 |
| --- | --- |
| `ui-ux-pro-max` | 产品适配、UI 风格、色板、字体、UX 判断 |

| `frontend-design` | Deno 驱动的 token、色板、字体、CSS 分析和可访问性检查 |
| `tailwind-design-system` | Tailwind 设计系统和组件库结构 |
| `nextjs-app-router-patterns` | Next.js App Router、RSC、加载/错误状态、缓存 |
| `react-state-management` | React 客户端状态、服务端状态和 query 模式 |
| `web-component-design` | React、Vue、Svelte 可复用组件 |
| `design-system-patterns` | tokens、主题和可扩展组件治理 |
| `visual-design-foundations` | 字体、层级、色彩、间距和布局审查 |
| `interaction-design` | 流程、反馈、可感知 affordance 和交互行为 |
